# Feature migration sequence

Each item is a separate feature branch and PR; dependent work follows review/merge of its prerequisites.

1. **Simulation engine**: import TypeScript source; deterministic event log, seasonal resources, interventions, and regression tests. Disclose tuned assumptions and missing snapshot support.
2. **Companion roles and creature addition**: explicit dog/cat/visitor profiles, capacity limits, independent IDs, arrival feedback; no biological inference from appearance.
3. **Procedural puppet motion**: gait library, joint solver, sprite cuts, rig validation, browser review preview; separate articulated and whole-image fallback movement.
4. **Living forest UI**: approved art manifest, terrain constraints, actual engine-driven movement, creature cards, keyboard and reduced-motion support. Verify asset rights and event reuse eligibility first.
5. **Experiment replay**: full snapshot including imports and RNG, paired worlds, versioned scenario export/import, repeatability tests and multi-seed outcomes. Implemented as exact replay plus ten future-randomness continuations from fixed creatures/resources; these are within-model sensitivity checks, not independently initialized ecosystems or real-world confidence intervals.
6. **Meta creature pipeline**: real SAM and Muse Image adapters, one reviewed image per pet, reusable processed assets, accessories, costs and bounded jobs. The local adapters and review flow are implemented and tested offline; eligible funding, live payload verification and varied-photo reliability are still outstanding. See [the bridge guide](meta-creature.md).
7. **Meta custom experiments**: implemented with typed rainfall/removal interventions, exact prepared questions, manual controls, clarification/rejection validation and event-referenced explanations. One live Meta custom proposal succeeded; Baseten and live evidence selection remain unverified. [Details](investigation.md).
8. **Classroom activity**: implemented prediction, results inspection, learner-first explanation, teacher guide, printable worksheet, model-only rerun and observation protocol. No participant sessions/learning outcomes yet. Implemented together with step 7 because the evidence and learner-response flow share one vertical slice.
9. **Photo-inspired place map**: fixed topology, reviewed visual skin, explicit limits on measured versus generated content; only after the main journey works.

The first PR proves engine behavior, not the complete product or ecological validity. Broad parameter calibration and real Meta integration are separate acceptance work. Public assets and uploaded photographs do not migrate automatically.

The [indirect contributions plan](indirect-contributions.md) adds reusable examples, an experiment format, a question evaluation set and a teacher pilot to the existing feature milestones. It does not add separate products to the migration queue.
