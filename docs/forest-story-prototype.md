# Forest story and movement study · October 30, 2026

This is a separate review surface. It does not replace the existing forest or change its rules. The owner requested four lesson frames and one convincing movement prototype before a broad simulation-UI rebuild.

## Review

- `/forest-story.html`: a playable four-scene study: meet, predict, watch, reflect/connect.
- `/examples/forest/story-frames.html`: all four scenes at once. The observation/reflection frame links open at week 13, paused, for visual inspection.
- `/examples/forest/animal-acting.html`: fox walk-left/right, pivot, stop, pause and reduced-motion review.
- `/examples/forest/story-phone.html`: actual 390 × 844 iframe layouts, not device emulation.

The study uses warm paper, green/rust accents, larger controls, short prompts and one teaching task at a time. It explicitly selects one real model rabbit for its close-up rather than displaying every population. All populations still run in both model branches. The focused view is not a population-count display; its options explain the selective illustration. A foreground tree provides decorative framing, not new collision geometry.

The story has no provider adapter or paid call. It uses existing Meta artwork, the accepted fox atlas and original deterministic model/replay modules. No new art, weights, source photographs or generation receipts are included.

## What actually happens

`story-session.ts` creates the same complete starting forest and the existing typed experiment: half rainfall for 52 model weeks. It captures weeks 0–13 for presentation. The story clock reads those states and interpolates positions/food strokes; it does not consume model random draws or advance the simulation differently on a slower device. Reflection is kept before revealing the connection.

The highlighted patch is an actual open model food cell near the selected rabbit, selected for a readable difference in this fixed example. Surrounding strokes read their own cells. Stroke height/colour are illustrative mappings of model food, not plant geometry, measured biomass or a full habitat reconstruction. The comparison changes the branch while keeping the same patch, camera and elapsed week. The title/condition label update together.

The user can tap an observation (including not sure), then optionally write. A version-2 experiment download retains the prediction/reflection and the complete starting state. It can be opened with the existing replay implementation. The short story observes the first 13 weeks, not the full year; it does not claim that fewer rabbits must follow reduced rain.

## Motion scope

The fox reuses 24 locally cached poses. Visible foot-line offsets align each frame to the same ground plane. Phase follows travel distance, with a brief visual pivot before reversing, a contact shadow, rest pose and restrained breathing. This remains an artistic 2D cutout with a fixed source head/torso, not reconstructed anatomy or validated animal locomotion.

The rabbit uses explicit whole-image hop motion along the model positions and a small greeting reaction. It has no new articulated leg/head rig. The deer gait is still unaccepted for this experience and is not presented as repaired. The two supported presentation actors share drawing utilities; this has not yet replaced the old game's two renderers.

The movement page reports a rolling local canvas-draw timing sample. It excludes browser compositing, loading and full device frame-rate behaviour; it is not a general performance benchmark. Ordinary motion is local. Offscreen/hidden lesson views stop progressing; pause and reduced-motion controls are available. Existing creature creation, narration and free-exploration interfaces remain separate.
