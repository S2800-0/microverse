## What is and is not measured

The new world builder is a **bounded teaching system**, not a general pretrained world model or a scientific reconstruction. It supports producer/grazer/predator/companion roles, rooted/walk/hop/swim/fly motion and reviewed event types. Local deterministic rules decide food, heat/water effects, encounters and arrivals; invented rates are not species-calibrated. Terrain uses bounded water zones, not measured collision masks or recovered 3D geometry. A photo cannot establish unseen species, food supply or ecosystem health. The compiler corrected the real plan's incorrect coral-as-producer suggestion to algae before running it.

Garden and woodland still reuse the curated land food web with distinct paintings. Only the garden has recorded SAM masks. Live SAM segmentation of arbitrary landscapes is not connected to the new world-builder interface; Spark vision plans the scene. The new general engine does not make every biome scientifically valid. Snow/rain routing is implemented but a real snow-photo flow has not been demonstrated.
