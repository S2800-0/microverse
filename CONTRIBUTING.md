# Contributing to Microverse

Thanks for your interest. Bug reports, ideas and pull requests are all welcome.

## Getting started

```bash
npm install
npm run dev
npm test
```

You need Node.js 24 or newer. No API key is needed for the saved worlds, lessons or tests.

## Pull requests

- Keep each change small and focused.
- Add or update a test when you change behavior.
- Run `npm test` and `npm run build` before opening the pull request.

## Please keep these true

- **Never commit keys, `.env` files or spending ledgers.**
- **Check the rights of anything you add.** Photos, art and music need a license that allows redistribution, recorded in `docs/CREDITS.md`.
- **Keep claims honest.** Don't describe the simulation as a forecast, or say something is AI understanding when it's a rule.
- **Keep lessons sourced.** Lesson cards are in our own words, from a source whose terms allow it.

## Reporting a security problem

Please don't open a public issue for a security problem. Contact the maintainer through their GitHub profile instead.
