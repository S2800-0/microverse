The game is one use for these tools. Borrow a piece for a classroom activity, an interactive story, or your next experiment.

01

MICROVERSE ECOSYSTEM

A world you can
run again.

A deterministic toy ecology engine, complete snapshots and paired experiments. Change rainfall, compare the records, then reopen the same saved experiment.

Use it for a small learning activity or a reproducible simulation prototype. No model key is needed. Its rules are illustrative, not a calibrated environmental forecast.

Open the repository ↗Run the example ↗
02

MICROVERSE PUPPETS

A painting with
a few new moves.

Browser-local cutout fitting, textured limb movement and an explicit review step. Start with the synthetic example or a transparent quadruped PNG; choose simpler movement if the rig does not work.

Use it for story characters or interactive illustrations. It runs locally, without uploading the image or calling an AI model. Geometry checks are not anatomy checks.

Open the repository ↗Try the browser demo ↗
03

MICROVERSE COMMANDS

A question.
A reviewable change.

Prepared ecology questions and strict typed proposals for rainfall or native-species removal. Unsupported changes stay unsupported; numeric mismatches can become clarification.

Use it as a small starting point for a constrained experiment interface. It does not execute commands itself or guarantee that every natural-language interpretation is correct.
